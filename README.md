# Linkeria

Site estático da Linkeria, com página inicial e listas de produtos por post.

## GitHub Pages

Após enviar os arquivos à branch de publicação, abrir Settings → Pages → Build and deployment → Deploy from a branch e selecionar a branch e /(root). O arquivo .nojekyll mantém a entrega como site estático.

Os caminhos relativos funcionam tanto em um domínio próprio quanto em usuario.github.io/repositorio/.

## Conteúdo

A seleção de primavera está em prévia; os links foram fornecidos pela responsável pela Linkeria. As imagens são ilustrativas. Não há envio automático de direct nem monitoramento de ofertas configurado.
